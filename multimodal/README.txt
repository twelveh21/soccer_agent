多模态战术分析

本层后期接收用户上传的阵型图、战术板、比赛截图等视觉材料，将其转为带来源标识的证据，再交给现有 Solver。
视频理解成本高、评测困难，不在第一阶段实现；不能从静态截图推断未出现的比赛事件。

文件职责：

- `contracts.py`：定义上传材料与视觉证据的统一字段。
- `vision_service.py`：校验文件类型、提取 PDF/TXT 文本或调用视觉模型描述图片。
- `evidence_context.py`：把结果压缩为带 `input_id`、资料限制和长度上限的用户材料上下文，再交给 Agent。

视觉模型被要求返回受 Pydantic 校验的 JSON：可见阵型、可见人数、箭头、场地区域、文字标签、观察和不确定项。若模型未遵守 JSON 格式，系统不会硬解析或杜撰字段，而是降级为原始观察文本并降低置信度。

安全边界：浏览器声明的 MIME 类型不可信，因此服务会检查 PNG/JPG/WebP/PDF 文件头；视觉模型只能描述上传材料可见内容，不能将静态图像推断为已核验比赛事实。
