Agent Eval：运行质量评测

本目录评测 Agent 的“过程是否正确”，不只评价最终回答是否好读。

- `contracts.py`：一条 Agent 评测用例的预期行为，以及统一评测报告格式。
- `run_evaluator.py`：检查路由、节点轨迹、工具选择、引用可回溯性与资料边界披露。

输入是已经脱敏的运行摘要、最终回答和本轮可展示引用目录。评测不会调用模型、不会联网，因此可在本地和 CI 中稳定运行。

运行摘要来自 `RunRecorder`：每个 LangGraph 节点被 `observe_node` 包装，开始和结束时主动写入节点名、状态、耗时和安全元数据；模型调用单独记录角色、Token、耗时与按环境变量估算的成本。`run_evaluator.py` 现可将这些数据和评测用例中的预算作比较。
